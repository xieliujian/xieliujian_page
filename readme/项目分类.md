# 项目分类文档

本仓库是纯静态作品集站点（HTML + CSS + Vanilla JS，托管在 GitHub Pages），按用途把项目分成「游戏基础库」「作品集」「工具插件」三大类，游戏基础库内部再细分为 UPM 包与游戏工具。本文记录每个项目所属分类、所在目录、技术栈与线上地址，新增或下线项目时同步更新。

## 站点分区

首页 `index.html` 用 hash 路由切换一级分区，游戏基础库内用左侧 Tab 切换子分类：

| 分区 | hash | 说明 | 页面目录 |
| --- | --- | --- | --- |
| 游戏基础库 · Unity UPM 包 | `#libs-upm` | 以 UPM 包分发的运行时与编辑器模块 | `spacetime/` |
| 游戏基础库 · 游戏工具 | `#libs-tools` | 配表、热更、构建等配套工具 | `spacetime/` |
| 作品集 | `#works` | 可体验的作品与系统 Demo | `projects/` |
| 工具插件 | `#plugins` | 外部 Unity 插件资源库入口 | `plugins/` |

线上地址前缀：<https://xieliujian.github.io/xieliujian_page/>

## 一、游戏基础库 · Unity UPM 包

共 8 个模块，统一以 C# + UPM 形式分发，页面位于 `spacetime/<模块名>/index.html`。

| 项目 | 定位 | 技术栈 | 说明 | 源码仓库 |
| --- | --- | --- | --- | --- |
| com.spacetime.core | 核心运行时基础库 | C#、UPM | 基础框架、通用管理器、生命周期接口，是其他模块的依赖基础 | [com.spacetime.core](https://github.com/xieliujian/com.spacetime.core) |
| com.spacetime.gpuskin | GPU 蒙皮与大批量角色 | C#、Shader | 动画烘焙到贴图后在 Shader 采样，配合 GPU Instancing 与全局帧降低 CPU 与 Draw Call | [com.spacetime.gpuskin](https://github.com/xieliujian/com.spacetime.gpuskin) |
| com.spacetime.slg | 策略地图场景系统 | C#、Shader、URP | 网格地形、信息图层、场景线段、动态对象与 Editor 工具链；命名空间 ST.SLG，要求 Unity 2020.3+ | [com.spacetime.slg](https://github.com/xieliujian/com.spacetime.slg) |
| com.spacetime.terrain | 地形导出 | C#、UPM | 把 Unity Terrain 导出为网格模型，运行时加载模型地形替代 Terrain 组件 | [com.spacetime.terrain](https://github.com/xieliujian/com.spacetime.terrain) |
| com.spacetime.tool | 编辑器工具库 | C#、Editor | 封装 Editor 扩展、Inspector 辅助工具与构建脚本 | [com.spacetime.tool](https://github.com/xieliujian/com.spacetime.tool) |
| com.spacetime.effect | 特效系统基础库 | C#、Shader、URP | 粒子系统管理、Shader 特效与后处理，提供统一特效调用接口 | [com.spacetime.effect](https://github.com/xieliujian/com.spacetime.effect) |
| com.spacetime.pvs | 潜在可见集基础 | C#、PVS | PVS 数据与运行时基座，用于大场景可见性剔除与查询 | [com.spacetime.pvs](https://github.com/xieliujian/com.spacetime.pvs) |
| com.spacetime.pvswrap | PVS 集成层 | C#、PVS | 对 com.spacetime.pvs 的封装与 Unity 侧接入，需搭配 pvs 使用 | [com.spacetime.pvswrap](https://github.com/xieliujian/com.spacetime.pvswrap) |

模块间依赖：core 为公共底座；pvswrap 依赖 pvs；slg、terrain、gpuskin、effect 面向具体场景能力，可按需引入。

## 新增项目维护清单

1. 新建目录：作品放 `projects/<名称>/`，基础库或工具放 `spacetime/<名称>/`。
2. 页面复用现有 class（`.project-card`、`.lib-row`、`.unity-container`），样式统一写在 `style.css`，子页面引用 `../../style.css`。
3. 在首页登记：作品加到 `#panel-works` 的 `.projects-grid`；库或工具加到对应 `.lib-list`。
4. 更新本文对应的分类表格。
5. 有 WebGL 构建时，Unity 的 Compression Format 设 Disabled，产物放 `webgl/` 或 `Build/`。
6. 封面图放 `assets/thumbnails/`，命名与项目目录一致（16:9）。
